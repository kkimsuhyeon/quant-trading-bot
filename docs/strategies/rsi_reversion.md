# RSI 과매도 반등 (RSI Reversion)

- **유형**: 평균회귀 (mean-reversion)
- **상태**: 검증 중 — Phase 2 백테스트 완료, Phase 3 OOS 검증 대기.
- **코드**: `strategies/rsi_reversion.py` (`RsiReversion`)
- **가설**: [`notes/hypothesis_rsi_reversion.md`](../../notes/hypothesis_rsi_reversion.md)

## 한 줄 요약
RSI가 **30 미만으로 과매도**되면 사고, **50을 회복**하면 판다.

## 시장에 대한 믿음
"과도하게 팔려(RSI<30) 단기적으로 과매도면, 평균으로 단기 반등할 확률이 높다."
최근 가격 낙폭이 지나치게 크면 곧 되돌림이 온다는 단기 회귀 가설.

## 지표
- **RSI(14)**: 최근 14봉의 상승폭 대비 하락폭 비율 — 0~100 범위. 30 미만 = 과매도 구간.

## 규칙
| 조건 | 동작 |
|---|---|
| RSI(14) < 30 (과매도), 포지션 없음 | 매수 + 진입가 대비 **-5% 손절** 설정 |
| RSI(14) > 50 (중립 복귀) | 청산 |

- 룩어헤드 방지: 완성된 봉의 종가 기준 신호, 주문은 다음 봉 시가 체결(`trade_on_close=False`).
- 손절: 진입가 × 0.95 — 추세 하락 시 "떨어지는 칼날" 방어.

## 파라미터
| 이름 | 기본값 | 의미 |
|---|---|---|
| `rsi_period` | 14 | RSI 계산 기간(봉) |
| `oversold` | 30 | 과매도 기준선 (진입 조건) |
| `exit_level` | 50 | 중립 복귀 기준선 (청산 조건) |
| `stop_loss_pct` | 0.05 | 손절 비율 (5%) |
| `use_sentiment` | False | sentiment 스위치 (자리만, 미구현 — Phase 5) |

## 잘 되는 장세 / 깨지는 장세
- **잘 됨**: 횡보장 — 가격이 일정 범위에서 오르내릴 때 과매도 → 반등 패턴이 반복.
- **깨짐**: 강한 하락 추세 — 과매도가 계속 연장되어 손절이 반복 발동.

## 결과 (참고)
BTC/USDT 1h, 약 3년, 수수료 0.1%/side:

| 지표 | 값 |
|---|---|
| 수익률 | **-46.6%** |
| Buy & Hold 수익률 | 101.8% |
| 샤프 | -1.03 |
| MDD(최대낙폭) | -58.8% |
| 승률 | 59.2% |
| 거래 수 | 218 |

→ 승률(59%)은 SMA보다 높지만, 수익률은 더 나쁘다.
손절에 걸리는 패배 거래의 손실이 반등 거래의 이익보다 크기 때문.
BTC처럼 장기 상승 추세가 있는 자산에서 공매수만 하는 평균회귀 전략의 전형적 한계.
Phase 3 OOS 검증에서 버릴 기준: Buy & Hold 미달 또는 파라미터 민감도에서 결과 붕괴.
