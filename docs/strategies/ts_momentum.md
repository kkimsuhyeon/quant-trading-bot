# 시계열 모멘텀 (Time Series Momentum)

- **유형**: 모멘텀 (momentum)
- **상태**: 검증 중
- **코드**: `strategies/ts_momentum.py` (`TimeSeriesMomentum`)
- **가설**: [`notes/hypothesis_ts_momentum.md`](../../notes/hypothesis_ts_momentum.md)

## 한 줄 요약
과거 N봉 수익률이 **양수면 사고**, **음수가 되면 판다.**

## 시장에 대한 믿음
"최근 N봉 동안 가격이 올랐으면 모멘텀이 살아있다 — 계속 오를 가능성이 높다."
추세추종이지만 이동평균 교차 대신 **절대 수익률** 부호(+/−)만 본다는 점이 다르다.

## 지표
- **모멘텀(mom)**: `close[t] / close[t−n] − 1` — 과거 n봉 대비 현재 수익률
  (현재 봉의 값만 사용하므로 룩어헤드 없음)

## 규칙
| 조건 | 동작 |
|---|---|
| 모멘텀 > 0 이고 포지션 없음 | 매수 (손절: 진입가 −5%) |
| 모멘텀 ≤ 0 | 청산 |

- 룩어헤드 방지: 현재 확정된 종가만 사용 (`close[-1]`).
- 주문: 다음 봉 시가 체결 (`trade_on_close=False`).

## 파라미터
| 이름 | 기본값 | 의미 |
|---|---|---|
| `lookback` | 30 | 모멘텀 계산 기간(봉) — 30봉 전 대비 수익률 |
| `stop_loss_pct` | 0.05 | 손절 비율 (진입가 대비 −5%) |
| `use_sentiment` | False | sentiment 스위치 (자리만, 미구현 — Phase 5) |

## 잘 되는 장세 / 깨지는 장세
- **잘 됨**: 지속적인 추세장 — 모멘텀이 꺾이지 않고 한 방향으로 지속될 때.
- **깨짐**: 빠른 반전장 / 횡보장 — 모멘텀 부호가 자주 바뀌어 거래 횟수가 폭증하고 수수료로 깎인다.

## 결과 (참고)
BTC/USDT 1h, 약 3년, 수수료 0.1%/side:

| 지표 | 값 |
|---|---|
| 수익률 | **−85.95%** |
| Buy & Hold | 99.82% |
| 샤프 | −2.64 |
| MDD(최대낙폭) | −86.08% |
| 승률 | 19.13% |
| 거래 수 | 1202 |

→ 6전략 중 최악. 1시간봉에서 모멘텀이 너무 자주 바뀌어 거래 횟수가 1202회에 달하고,
수수료 누적으로 자본이 거의 소진된다.
lookback=30봉은 1시간봉에서 너무 짧은 주기여서 노이즈를 모멘텀으로 오인한다.
