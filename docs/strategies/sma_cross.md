# SMA 교차 (SMA Crossover)

- **유형**: 추세추종 (trend-following)
- **상태**: hello world — 파이프라인 검증용. 수익 전략으로 검증된 것 아님.
- **코드**: `strategies/sma_cross.py` (`SmaCross`)

## 한 줄 요약
단기 이동평균이 장기 이동평균을 **위로 뚫으면 사고, 아래로 뚫으면 판다.**

## 시장에 대한 믿음
"가격에 추세가 생기면 한동안 지속된다." 단기 평균이 장기 평균을 위로 넘는다
= 최근 가격이 과거보다 높아지는 중 = 상승 추세 시작으로 본다.

## 지표
- **단기선(fast)**: 최근 20봉 종가의 단순이동평균(SMA) — 빠르게 반응
- **장기선(slow)**: 최근 50봉 종가의 단순이동평균 — 천천히 반응

## 규칙
| 조건 | 동작 |
|---|---|
| 단기선이 장기선을 **위로** 돌파 (골든크로스) | 매수 |
| 단기선이 장기선을 **아래로** 돌파 (데드크로스) | 청산 |

- 룩어헤드 방지: 신호는 완성된 봉으로만 계산, 주문은 다음 봉 시가에 체결(`trade_on_close=False`).
- 포지션: 가용 자본 전부(소수점 매수). **손절·킬스위치 없음** (hello world라 생략, Phase 2부터 도입).

## 파라미터
| 이름 | 기본값 | 의미 |
|---|---|---|
| `fast` | 20 | 단기 SMA 기간(봉) |
| `slow` | 50 | 장기 SMA 기간(봉) |
| `use_sentiment` | False | sentiment 스위치 (자리만, 미구현 — Phase 5) |

## 잘 되는 장세 / 깨지는 장세
- **잘 됨**: 뚜렷한 추세장 — 한 방향으로 길게 움직일 때.
- **깨짐**: 횡보장 — 단기·장기선이 자주 엇갈려 잦은 매매(휩쏘) → 수수료로 까먹음.

## 결과 (참고)
BTC/USDT 1h, 약 3년, 수수료 0.1%/side:

| 지표 | 값 |
|---|---|
| 수익률 | **-26.5%** |
| 샤프 | -0.33 |
| MDD(최대낙폭) | -53.7% |
| 거래 수 | 308 |

→ 진다. 단순 추세추종이 수수료 끼면 횡보 구간에서 깎인다는 전형적 결과.
