# 볼린저 하단 반등 (Bollinger Reversion)

- **유형**: 평균회귀 (mean-reversion)
- **상태**: 검증 중 — Phase 2 백테스트 완료, Phase 3 OOS 검증 대기.
- **코드**: `strategies/bollinger_reversion.py` (`BollingerReversion`)
- **가설**: [`notes/hypothesis_bollinger_reversion.md`](../../notes/hypothesis_bollinger_reversion.md)

## 한 줄 요약
가격이 **볼린저 하단(평균-2σ)을 하향 이탈**하면 사고, **중심선(20 SMA)으로 복귀**하면 판다.

## 시장에 대한 믿음
"가격이 볼린저 하단(평균-2σ) 아래로 벗어나면 통계적으로 과도한 이탈이라,
중심선(평균)으로 회귀할 확률이 높다."
정규분포 가정 하에 하단 이탈은 약 2.3% 확률의 극단값 — 곧 회귀한다는 통계적 기대.

## 지표
- **볼린저 밴드(20, 2σ)**: 20봉 SMA를 중심으로 ±2 표준편차 구성.
  - 중심선: 20봉 SMA
  - 하단밴드: 20봉 SMA − 2 × 표준편차

## 규칙
| 조건 | 동작 |
|---|---|
| 종가 < 하단밴드(20, 2σ), 포지션 없음 | 매수 + 신호 종가 기준 **-5% 손절(proxy)** 설정 |
| 종가 > 중심선(20 SMA) | 청산 |

- 룩어헤드 방지: 완성된 봉의 종가 기준 신호, 주문은 다음 봉 시가 체결(`trade_on_close=False`).
- 손절: 신호 캔들 종가 × 0.95 (proxy; `trade_on_close=False`라 실제 진입은 다음 봉 시가) — 추세 하락 시 밴드를 타고 계속 내려가는 케이스 방어.

## 파라미터
| 이름 | 기본값 | 의미 |
|---|---|---|
| `bb_period` | 20 | 볼린저 밴드 기간(봉) |
| `bb_std` | 2 | 밴드 폭 (표준편차 배수) |
| `stop_loss_pct` | 0.05 | 손절 비율 (5%) |
| `use_sentiment` | False | sentiment 스위치 (자리만, 미구현 — Phase 5) |

## 잘 되는 장세 / 깨지는 장세
- **잘 됨**: 횡보장 — 가격이 밴드 내에서 진동할 때 하단 이탈 → 중심 복귀 패턴 반복.
- **깨짐**: 추세 하락 — 밴드를 타고 계속 내려가면서 손절 반복 발동.

## 결과 (참고)
BTC/USDT 1h, 약 3년, 수수료 0.1%/side:

| 지표 | 값 |
|---|---|
| 수익률 | **-73.8%** |
| Buy & Hold 수익률 | 101.6% |
| 샤프 | -2.17 |
| MDD(최대낙폭) | -75.2% |
| 승률 | 59.5% |
| 거래 수 | 521 |

→ 3전략 중 최저 성과. 거래 횟수(521)가 가장 많아 수수료 누적이 크고,
손절 발동 시 손실도 RSI 대비 더 자주 반복됨.
승률(59.5%)은 셋 중 가장 높지만 손익비가 나빠 전체 수익률은 최저.
BTC 상승 추세 구간에서 롱 진입 후 손절 반복이 주된 원인.
Phase 3 OOS 검증에서 버릴 기준: Buy & Hold 미달 또는 파라미터 민감도에서 결과 붕괴.
