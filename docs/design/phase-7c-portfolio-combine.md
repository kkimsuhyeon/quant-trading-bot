# Phase 7c — 추세 + 캐리 2-엣지 포트폴리오 (개념검증)

> Phase 7의 *본체*(포트폴리오 결합, 가드레일 8). 7a(다코인)=분산 실패, 7b(캐리)=무상관 엣지 발견.
> 이제 그 둘을 **실제로 묶어** "무상관 엣지를 더하면 곡선이 매끈해지나"를 본다. Codex 자문 반영.

## 개요 / 목표 (강하게 한정)

**질문 하나:** *"검증된 추세 엣지에 무상관(상관 ~0) 캐리 sleeve를 더하면, 합쳐진 곡선이 추세 단독보다 매끈해지나(MDD↓ / Sharpe↑)?"*

- 7a가 못 준 답이다. 7a는 "코인을 늘리는" 분산이었고 크립토 고상관 탓에 평균화로 끝났다.
- 7c는 "**서로 다른 종류의 엣지**(추세 vs 캐리, 상관 ~0)를 더하는" 진짜 분산을 본다.
- **이건 "실거래 포트"가 아니라 "무상관 양수 sleeve를 더하면 *수학적으로* 곡선이 개선되는지"의 개념검증이다.** (Codex 4)

## 왜 (메커니즘)
두 수익원의 상관이 낮으면 합친 포트의 분산(변동성)은 각각의 가중합보다 작아진다(분산투자 수학).
추세와 캐리는 상관 ~0(7b 확인)이라, 이론상 합치면 변동성↓ → Sharpe↑·MDD↓ 가 나와야 한다.
**7c는 이 이론이 우리 데이터에서 실제로 나타나는지**를 본다.

## 무엇을 비교하나 (BTC — 단일자산, 두 엣지)
1. **검증된 추세 4전략 각각 vs BTC 캐리, 50/50 결합** (Regime/Keltner/Donchian/SMA+손절):
   각 전략에 대해 **추세 단독 / 캐리 단독 / 50:50 결합**의 Return·MDD·Sharpe(일간 기준) 비교.
   → "어떤 추세전략과 묶어도 개선되나"라는 견고성 확인 (한 전략 우연 배제).
2. **대표(Keltner)에 가중 민감도**: 70/30 · 50/50 · 30/70. 비중을 바꿔도 개선이 견고한지.
   **임계/비중 최적화 금지** — 사전 고정한 세 점만 본다. (Codex)

## 검증 기준 (무엇을 보면 "메커니즘이 작동"인가)
- **핵심:** 50/50 결합의 **MDD가 추세 단독보다 얕고 + Sharpe가 추세 단독보다 높은가.** (둘 다면 분산 작동.)
- 가중 민감도 3점에서 방향이 일관된가(전부 개선이면 견고, 한 점만이면 의심).
- 4개 추세전략 전부에서 같은 방향인가.

## ⚠️ 정직한 한계 (★★ Codex — 숫자가 좋게 나올 수밖에 없어서 더 중요)
- **결합 Sharpe는 과도하게 좋게 나온다 = 최대 함정.** (Codex 4) 캐리 v1은 tail risk(basis·청산·거래소)를
  뺀 gross라 비정상적으로 매끈하다 → 거기에 50/50으로 섞으면 결합도 **당연히** 매끈해진다.
  **이건 "분산이 작동했다"가 아니라 "매끈한 가짜 sleeve를 섞었다"의 결과일 수 있다.** 판정은
  "실거래 포트 개선"이 아니라 "**무상관 양수 sleeve를 더하면 수학적으로 곡선이 개선되는지**"로만 읽는다.
- **체결 가능 곡선이 아니다.** (Codex 3) 일간 종가로 맞춘 **mark-to-market sleeve blend**이고, 실제
  체결 비용·슬리피지는 빠졌다. `combine_sleeves`는 **초기 가중치로 배분한 뒤 방치하는 static weighted
  blend**다 — 매 시점 고정비중으로 리밸런싱하는 게 아니라 각 sleeve를 첫값 정규화·가중해 합산하므로,
  **시간이 지나면 가중치가 표류**한다(잘 가는 sleeve의 비중이 커짐). 따라서 **리밸런싱 비용은 모델링하지 않았다.**
- **공통창이 결과 기간을 바꾼다.** (Codex 1) dropna로 양쪽 다 있는 구간만 본다 → BTC 추세+BTC 캐리는
  시작일이 거의 같아 무해하나, 결과 기간이 원본과 다를 수 있음을 명시.
- **결과가 좋아도 Phase 4 후보 아님.** 캐리 실행현실성(**7b-v2**) 통과 전까진 **"portfolio concept proof"** 로만 둔다.

## 결과 (BTC 4h 추세 + BTC perp 캐리, 일간 결합·공통창, periods_per_year=365)

추세 단독 / 캐리 단독 / 50:50 결합 — 모두 **같은 일간 공통창**에서 측정 (combine_sleeves 가중 분리).

| 추세전략 | 구성 | Return% | MDD% | Sharpe |
|---|---|---|---|---|
| Regime | 추세 단독 | 202.5 | -33.9 | 0.81 |
| | 캐리 단독 | 37.0 | **-0.4** | **14.12** |
| | **50:50 결합** | 119.8 | **-23.7** | **0.85** |
| Keltner | 추세 단독 | 83.1 | -35.8 | 0.62 |
| | **50:50 결합** | 60.0 | **-22.8** | **0.72** |
| Donchian | 추세 단독 | 50.0 | -44.8 | 0.41 |
| | **50:50 결합** | 43.5 | **-22.4** | **0.51** |
| SMA+손절 | 추세 단독 | 45.4 | -52.9 | 0.39 |
| | **50:50 결합** | 41.2 | **-27.4** | **0.50** |

→ **4전략 전부 MDD↓ & Sharpe↑.** Return은 낮아진다(캐리 수익 ~37%가 추세보다 낮아 가중 평균이 내려감) — 그러나 **위험대비(Sharpe)·낙폭은 예외 없이 개선** = 분산 메커니즘 작동.
(추세단독 수치는 일간 리샘플·공통창 기준이라 2e의 raw 4h와 미세하게 다름.)

### 가중 민감도 (Keltner, 캐리 비중↑)
| 가중(추세/캐리) | Return% | MDD% | Sharpe |
|---|---|---|---|
| 70/30 | 69.3 | -29.0 | 0.65 |
| 50/50 | 60.0 | -22.8 | 0.72 |
| 30/70 | 50.8 | **-14.4** | **0.91** |

→ 캐리 비중↑일수록 **MDD 단조 감소·Sharpe 단조 증가** = 방향 일관(견고).

## 판정
✅ **질문 — "무상관 엣지를 더하면 곡선이 매끈해지나?" → 메커니즘은 그렇다.**
- 4전략·전 가중에서 MDD↓·Sharpe↑가 일관되게 나타남. **7a(다코인)가 못 준 "진짜 분산"의 첫 양성 신호.**
- 7a와 대조: 코인을 늘리는 분산은 고상관 탓에 평균화로 끝났지만, **종류가 다른 엣지(추세 vs 캐리, 상관~0)를 더하니 위험대비가 개선**됐다.

## ⚠️ 정직한 한계 (★★ Codex — 개선폭이 과장됐다)
- **개선폭의 일부는 진짜 분산이 아니라 "매끈한 가짜 sleeve를 섞은" 효과다.** 캐리 단독이 **MDD -0.4% / Sharpe 14** (gross 환상 — tail risk 제외)라, 거기에 섞으면 결합도 기계적으로 매끈해진다. **메커니즘은 입증됐지만 크기(특히 MDD 개선)는 과장.** 실제 net 캐리(basis·청산·거래소 위험 반영)면 개선폭은 더 작다.
- **체결 가능 포트가 아니다.** 초기 가중치 배분 후 방치하는 static weighted blend(가중치 표류, 리밸런싱 비용 미모델링), 체결 비용·슬리피지 제외.
- **결과가 좋아도 Phase 4 후보 아님.** 캐리 실행현실성(**7b-v2**) 통과 전까진 **"portfolio concept proof"** 로만 둔다.
