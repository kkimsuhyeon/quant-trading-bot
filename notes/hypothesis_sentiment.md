# 가설 — sentiment 오버레이 (Fear&Greed, Phase 5)

- **시장에 대한 믿음**: 군중 심리가 **극탐욕(Fear&Greed ≥ 75)**에 도달하면 과열/거품 구간이라, 가격 추세만으로는 안 보이는 tail/반전 위험이 커진다. 이 구간을 피하면 추세전략의 낙폭이 줄어든다.
- **진입 규칙**: 기존 검증된 추세전략(Regime/Keltner)의 진입 규칙 그대로. 단 `use_sentiment`가 켜져 있고 직전 확정 F&G ≥ 75면 **신규 진입 차단**.
- **청산 규칙**: 직전 확정 F&G ≥ 75면 **현금 청산**(보유 중이어도). F&G < 75로 내려오고 추세 신호가 살아있으면 재진입. (이건 **리스크 회피 오버레이**이지 매수 신호도, 숏도 아니다.)
- **버릴 기준**: Regime에서 baseline 대비 MDD 개선(상대 10%+ 또는 의미있는 pp) **그리고** Sharpe ≥ baseline **그리고** Return ≥ baseline의 80% **그리고** turnover 폭증 없음 **그리고** 구간 다수 개선 — 이걸 못 채우면 폐기. Regime에서 실패하면 Phase 5 MVP 실패로 본다.
- **장세 적합/취약**: 거품 천장 직전(추세 long + 극탐욕 발산)에서 방어 효과 기대. 단 **추세가 극탐욕 구간에서도 더 오르는 장**에선 추세 수익을 깎아 오히려 해로울 수 있음(흔한 결과 — 그래도 valid).
